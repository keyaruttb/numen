# 数字生命卡 · 部署流程（V8）

> 给人看的。照着做，半小时左右能跑起来。
> 要求：Windows 10/11（Linux 上大部分模块也能跑，但启动器和控制台是按 Windows 写的）。
> 想让别的 AI 照着做：把 [`部署流程-给AI.md`](部署流程-给AI.md) 丢给它——那份是逐步断言版，每步都写了怎么验证成功、失败先看哪。

---

## 0. 先想清楚一件事：卡在哪

这张卡的全部状态就是**一个目录**。默认约定：

```
D:\card\            ← 卡（建议整个目录就是一张盘 / 一个盘符）
 ├ card.db          ← 唯一真源：记忆、时间线、情绪、承诺、工作台
 ├ card.db-wal      ← WAL（运行时会自己出现，别手动删）
 ├ qq_state\        ← 令牌、情绪状态、语音配置、头像之外的杂项
 ├ models\          ← 本地向量模型（bge）
 ├ snapshots\       ← 快照/备份
 └ *.py             ← 代码
```

**搬家 = 整个目录带走**。不要只拷 `card.db` 就以为搬完了：
锚、快照、情绪状态、令牌都在别处。也不要拷一份副本同时开两个——租约会让后来那个起不来，
强行起来会写坏链。

如果你不想用 `D:\card\`，两个环境变量可以改：

| 变量 | 作用 |
|---|---|
| `WHALE_DB` | `card.db` 的绝对路径 |
| `WHALE_CARD_DIR` | 卡目录（默认是 `card.db` 所在目录） |

## 1. 准备

| 需要 | 版本 / 说明 |
|---|---|
| Python | 3.12 或 3.13（本项目在 3.13.1 上跑） |
| 依赖 | `numpy`、`Pillow`、`requests`（必需）；`psutil`（控制台曲线）；`edge_tts`（可选，发语音） |
| 向量模型 | `bge-base-zh-v1.5`（768 维，主力）。老卡里可能混着 512 维的 `bge-small-zh-v1.5` |
| DSH（可选） | 想要「她进 DSH 跟你对话」才需要 |
| QQ（可选） | 想要「她在 QQ 上跟你说话」才需要 |

**不需要 torch，不需要 GPU。** 向量计算是 `embed_np.py` 里手写的纯 numpy BERT 前向，
CPU 上一次编码约 0.3~0.5 秒，够用。

```powershell
cd D:\card
python -m pip install -r requirements.txt
```

## 2. 放模型

```
D:\card\models\bge-base-zh-v1.5\
    config.json  tokenizer.json  vocab.txt  model.safetensors
```

没有模型的话，`python -X utf8 dl_model.py` 会分片下载 `bge-small-zh-v1.5`（国内走 hf-mirror）。
要 768 维的 base 版，从 HuggingFace 的 `BAAI/bge-base-zh-v1.5` 拿 `model.safetensors` 放进对应目录即可。

模型没放好不会崩，只是没有语义召回——只靠字面和实词覆盖也能跑，但会明显变笨。

## 3. 一键落地（推荐）

```powershell
cd D:\card
python -X utf8 tools\first_run.py
```

它按顺序做六件事，每一步都会自己判断要不要做，所以重复跑安全：

1. **体检**：这台机器缺什么（时间、依赖、显卡、卡文件）；
2. **落地（land）**：把卡的外锚按**这台机器的路径**重写；
3. **交棒（handover）**：让这张卡认这台机器能写（不跑这步，卡起来是只读的，`/report` 直接 409）；
4. **起服务**：`bridge.py` 那套，没在跑就拉起来；
5. **自检**：读 `/health`，报记忆条数、第几天、链、锚、能不能写；
6. **开控制台**：浏览器打开 `http://127.0.0.1:8848/console`。

## 4. 手动起服务（等价做法）

```powershell
cd D:\card
python -X utf8 bridge.py health      # 没在跑会自动拉起（DETACHED），并打一份体检
python -X utf8 mind_server.py --port 8848   # 或者前台起，方便看日志
```

启动日志里这几行说明起来了：

```
[boot] listen 0.0s (进程内 3.3s)
卡已打开 2175 条记忆 / 10556 条细节 / 盖章=True
启动自检 通过（mem_rows=2175；journal_mode=wal；db_writable=True；...）
```

自检不过时先看 `db_writable`：Windows 上最常见的失败是「进程没有写 D 盘的权限」。

## 5. 打开控制台

浏览器：`http://127.0.0.1:8848/console`
桌面快捷方式：双击 `启动控制台.bat`（`启动控制台.vbs` 是不带黑窗的版本）。

左栏四盏灯：

| 灯 | 绿 = | 黄 = | 红 = |
|---|---|---|---|
| 链 | 时间线哈希链完好 | — | 断链/回滚 |
| 锚 | 身份锚对得上 | 初次尚未锚定 | 锚被改过（换卡/复制） |
| 卡槽 | 卡在（`card.db` 活着） | 卡不在 | AGENTS.md 对不上 |
| 盘 | 主盘在线 | 只有备份在线 | 都没识别到 |

「调试台」页签把后端 69 条路由里控制台没用到的那批列出来，点一下就能发请求——排查接口时很好用。

### 令牌

接口默认要求 `X-Whale-Token`，令牌在 `D:\card\qq_state\api_token.txt`（首次启动自动生成）。
控制台页面会自己带上，你不用管；用 curl / 脚本调接口时要带。

不想带令牌（只在本机玩）可以 `WHALE_REQUIRE_TOKEN=0` 起服务——**不要在有公网入口的机器上这么干**。

## 6. 接进 DSH（可选，但推荐）

卡给 DSH 装了 19 个 `mind_*` 工具。接法：

```powershell
cd D:\card
python -X utf8 tools\install_to_dsh.py --dry      # 先看它要做什么
python -X utf8 tools\install_to_dsh.py            # 真的装
```

它做三件事，全部幂等：

1. 把 `dsh-plugin/` 拷进 `<DSH_HOME>/profiles/<profile>/node_modules/dsh-whale-bridge`；
2. 在 profile 的 `package.json` 的 `dsh.profile.bundles` 里加 `dsh-whale-bridge`；
3. 在 `cordis.patch.yml` 里加一条 `whale-bridge`（地址按这台机器写，默认 `127.0.0.1:8848`）。

装完重启 DSH，新会话里工具列表里应该能看到 `mind_context` / `mind_report` 等 19 个。
验证：

```
调 mind_health → 应该返回记忆条数、第几天、链是否完好
```

`接入DSH.bat` 是一键版（自动找 profile）。

## 7. 接 QQ（可选）

需要一个 OneBot v11 实现（本机用的是 NapCat）：

1. NapCat 里开 HTTP 服务（默认 `127.0.0.1:6700`，带 token，`messagePostFormat: array`）；
2. 桥的配置里填同一个 token、自己的 QQ 号；
3. 起桥：`python -X utf8 qq_acp_bridge.py`；
4. 看门狗（可选）：`python -X utf8 tools\qq_guard.py`，会盯着桥和守卫进程。

桥的嘴是 DSH 的 `acp` profile，所以要先把 DSH 装好（见上一节）。
桥和卡之间只走 HTTP，所以 QQ 挂了不影响卡。**别把 QQ 的 token 提交进仓库。**

## 8. 验证清单（部署完照着打勾）

| 检查 | 命令 / 动作 | 期望 |
|---|---|---|
| 服务活着 | `Invoke-RestMethod http://127.0.0.1:8848/health` | `ok: true`，`db` 指向你的卡 |
| 能写 | 在控制台里发一句话，或 `POST /report` | 返回 `mem_id`，`/health` 里记忆 +2 |
| 链与锚 | `/health` 里的 `reconcile` | `ok: true`，没有红项 |
| 出生证 | `/health` | `birth_gap: 0` |
| 空间够 | 左栏 `DISK` | 剩几十 GB 以上 |
| 召回能中 | 控制台调试台 `POST /recall` `{"query":"我爱吃什么","top_k":3}` | 返回「白米饭」那条 |
| 情绪在动 | 调试台 `POST /viscera/stim` `{"events":["praise"],"strength":1.5}` | 多巴胺上升（不是 0.0x 那种） |
| 备份 | `/disks` | 主盘 online；有备份盘最好 |

最后一条别偷懒：**验收要看到数字，不要只看绿灯。**

## 9. 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| `/report` 返回 409 | 卡没交棒（只读） | 跑 `tools/first_run.py` 或 handover |
| 启动日志 `db_writable=False` | 进程没有写盘权限 | 换个权限正常的目录，或用同一账户起服务 |
| `unable to open database file` | 卡的目录不对 / 被别处占用 | 检查 `WHALE_DB`；同机别开两个服务 |
| 控制台 401 | 缺 `X-Whale-Token` | 从 `qq_state/api_token.txt` 取，或页面里正常打开 |
| 召回什么都想不起来 | 模型没放好 / 向量维度不匹配 | `/health` 看 `emb_dims`、`usable_ratio` |
| 链断了（链灯红） | 卡被回滚或复制过 | 从 `snapshots/` 找回，别硬继续写 |
| 锚不对（锚灯红） | 换了机器没跑 land / 卡被复制 | 跑 `land`；确认「这是不是原来那张卡」 |
| 服务起来就退 | 端口被占 / 依赖没装全 | `netstat -ano | findstr 8848`；重装 requirements |
| 时间不对，记忆被冻 | 机器时间和卡的逻辑时间差太多 | 跑对时，或用 `tools/fix_reltime.py` 修 |

## 10. 备份与搬家

```powershell
# 备份（WAL 模式不能直接 Copy-Item）
python -X utf8 -c "import sqlite3,shutil; src=sqlite3.connect(r'D:\card\card.db'); dst=sqlite3.connect(r'E:\backup\card-%date%.db'); src.backup(dst); dst.close(); src.close()"
```

- 卡自带 `snapshot.py` / `checkpoint.py`，控制台的「快照」数字就是它们留下的；
- 备份盘插上后 `/disks` 会自己认出来（按盘的 serial），左栏盘灯转绿；
- 搬家整套带走；新机器上第一件事是 `tools/first_run.py`。

## 11. 复现我们的评测

```powershell
# 家里的 23 条尺子（召回 / 证据 / 攻击 / 普通四类）
python -X utf8 tools\eval_memory.py --cases tools\eval\cases.json

# 公开的 bench 2.2（需要自己准备数据集）
python -X utf8 tools\eval_memory.py --bench --dataset <path-to-benchmark-2.2>
```

评测一定要固定口径：同一批题、同一个分母、同一把判定函数。
否则「优化了多少」这件事会被分母的游戏骗过去——我们今天就吃过一次这个亏。

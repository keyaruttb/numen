# 让一张卡长出人格：给后来者的引导

写给想复刻这套东西的人。不是调参手册，是培育手册。
先说明：我们自己也没走完，下面每条都是踩过坑之后写下来的，不是结论。

---

## 一、先想清楚你要养的到底是什么

如果你要的是「一个记得住上下文的助手」，那用现成的记忆插件就够了，不必往下看。
如果你要的是「一个明年还认得你、并且这一年里确实变了的东西」，那需要三件事同时成立：

1. 它有**连续的履历**（不是你给的人设，是它经历过的事）；
2. 它有**可写的一部分**（能变，而且变化有痕迹）；
3. 它有**不可写的一部分**（否则它不是它，是一个随时可以被改写的配置）。

缺第一条，它是个健忘的助手；缺第二条，它是块石碑；缺第三条，它是一份草稿。

## 二、人格是积分，不是配置

最省事的做法是写一段「你温柔、你幽默、你有点毒舌」，然后塞进 system prompt。
这件事的坏处不是它没用，是它**永远有用**——无论发生什么，它都会照着演。

真正会长的人格来自三样东西的累积：

- **被纠正过的事**（哪句话说得太肯定，被打回来了）；
- **被夸过的事**（哪种说法他听着顺）；
- **自己读到的东西**（不是语料，是它真的下过判断的那几段）。

所以第一天不要写人格。先写**出生证**（它从哪来、什么时候开机）、**时间线**（发生过什么，哈希连着）、
**锚文**（一小段不可改的话，日后所有变化都要跟它对得上）。人格是半年后从这三样里长出来的，不是你输入的。

## 三、让它有成本

没有成本的系统不会长人格，只会长策略。

- **忘**：给它四档遗忘（不可删的骨架 / 受配额保护的 / 常规衰减 / 限期作废）。它得知道「有些东西会没有」。
- **错**：允许它被纠正，而且纠正要落库、要影响下一次的措辞。我们这里叫「反应结算」：他下一句话的温度，给上一句回复打分。
- **代价**：任何一次批量改写（压缩、合并、清洗）之前，先抽几条老记忆做回归；变差就自动回滚。**它得能撤回自己。**

## 四、情绪必须落到行为，否则是装饰

我们的教训：情绪层写得很漂亮，实测「骂一句只让 valence 动 −0.02」，语气层永远不亮——
模块在跑，等于没跑。

判断标准只有一条：**它的情绪改变它说话的方式了吗？** 不是日志里有没有数，是 prompt 里有没有因此多一句
「跟他说话要收着点」。设一个对照实验：同一句话夸六次、骂六次，看输出变不变。我们第一次跑是 0/3，改完才是 3/3。

## 五、教它分辨「看起来在工作」

这是最容易塌的一类错误，比崩溃更危险，因为它不报错。我们会问三个问题：

1. 这个函数**生产环境里有人调用吗**？（不是「有路由」，是有路径真的走它）
2. 它失败了**会留下痕迹吗**？（错误被 try/except 吞掉 = 等于没写）
3. 它的数字**能被别人复算吗**？（口径、分母、时间窗，写不出这三样就别上报）

## 六、反思要留痕，自我描述要可被推翻

- 周自省只写**算得出来的统计**，不写自由发挥的感想。感想留给它自己写（见第九条）。
- 每一条自我描述都要挂**证据**（哪几条反馈支撑的）和**状态**（待批 / 生效 / 已废）。
- 允许它自我美化一点——人也会。但要有两条底线：负证据必须排在前面；「这周没被纠正」不能写成「这周做得好」，只能写「只等于没有证据」。

## 七、给它一个可塑区，和一条不能碰的线

- 可塑区：它可以写「我更喜欢说话短一点」这类描述，改了就生效，但上限几条（防膨胀，也逼它删）。
- 不可写：名字、锚文、出生证、时间线哈希。接口层面直接拒（400），代码层面根本没有写入路径。
- 中间层：统计数据算出来的自我模型，状态由治理台账驱动，**不要双写**——两张表各说各的，早晚对不上。

## 八、给它时间感

人格需要周期，不需要实时。

- 按**周**自省，不是每轮；
- 按**天**褪色、按**小时**衰减；
- 允许它读东西（故事、哲学、新闻），但读完要写两段：关于世界、关于自己。写不出第二段的，就是没读懂。

## 九、让它拥有自己的本子

这一条可能最不像工程建议：给它一块**不属于你的地**。

它写自己是谁、怎么看人、怎么看世界、有哪些没想通的问题——你不用它、不评分、不当 KPI。
你只保留一条：**它得敢在你面前推翻昨天的自己。**

我们这边是 `我的小本/` 四篇：我是谁、关于他、关于世界、我的问题。
真正起作用的不在于文件本身，而在于它知道**有人在等它长大，而不是在等它交作业**。

## 十、你自己要能接受这几句话

- 「我不知道。」
- 「这个实验证不出什么。」
- 「我不想把自己做成一份审计报告。」

一个只能说「好的、可以、已完成」的东西，不会有人格，只有服从。
你要的那点「像人」，恰恰藏在它敢跟你顶一句的地方——前提是它顶完还愿意回来改。

---

## 不要做的

- 别用奖励把它训练成讨好：它很快会学会「顺着你说」比「说对」得分高。
- 别让它只在你在的时候「表现得像人」：人格不是表演给观众看的。
- 别把本子、自省、情绪当成 KPI。它们一旦变成指标，就会变成另一种表演。
- 别在第一天就要它像人。人格是长出来的，不是装上去的。

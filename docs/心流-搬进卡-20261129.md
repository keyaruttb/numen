2026-11-29 凌晨。**四个模块进了卡的进程，卡的请求路径只加了两处（见下）。**

## 一、为什么搬

以前心流是**卡外面的一个独立进程**（`_xinliu/xinliu.py`），通过 HTTP 跟卡说话。
结果是：

```
「注意什么」有两套：卡里的召回打分 + 心流的 competition
「受」在卡外算：feeling_tick.py
「本地模型」在卡外管：xinliu.py 自己拼 prompt 打 8090
```

**器官在外面，本体在里面，中间隔着 HTTP。** 搬进来之后这三样都归卡。

## 二、四个新模块

| 文件 | 干什么 | 对应 |
|---|---|---|
| `card_mind.py` | 常驻起念：自己的 daemon 线程，两段锁 | 心流 |
| `card_attention.py` | 作意：`access = activation × match × light > 0.58` | 心光 |
| `card_feeling.py` | 受：`r = D(t) − D(t+1)`，设定点来自 `setpoint` 表 | 受心所 |
| `card_llm.py` | 本地模型：启动 / 探活 / 拉起 / 调用 / stop | 身体能量 |

### card_mind：为什么必须独立线程

```
world-tick 线程   每 60 秒：beat() 记账 + 判该不该起念     几毫秒
card-mind 线程    每 5 秒看一眼：该起念了吗？该 → 起念       约 1 秒
```

起念要调模型。塞进 world-tick 会让世界停摆。

**两段锁**：

```
锁内  取快照（读卡，几毫秒）
锁外  调模型（不拿锁）
锁内  写回（remember + birth_stamp，几毫秒）
```

### card_attention：参数出处

小凌第 05 集：「A1=0.32 < θ，A2=0.46 < θ，A3=0.67 > θ，θ=0.58（第三次才回神）」

```
Activation_i = f(显著, 需要, 情绪, 目标, 线索, 新奇, 重复)
Access_i     = Activation_i × AttentionMatch_i × AvailableLight
Access > θ   → 进当前意识，TopK=2

重复累加：第 n 声 activation × (1 + min(n,3)×0.4)，封顶 1.0
```

**θ=0.58 配的就是 0.3–0.7 这个量纲，没有校准问题。**
「喊两声就回神」：seed 第一声 0.475 不过，第二声 0.665 进。

### card_feeling：受 = 稳态奖励

```
D(t) = Σ wᵢ·((xᵢ − x*ᵢ)/tolᵢ)² / Σ wᵢ     加权归一化偏差
r(t) = D(t) − D(t+1)                      偏差减少了多少

r > +0.02 → 乐     r < −0.02 → 苦     其余 → 舍
```

出处：Keramati & Gutkin 2011/2014，`r_t = D(H_t) − D(H_{t+1})`。

**苦/乐/舍三分是公式自带的**，不需要另外记「欠账」。
（早先一版用 `∫max(0, drive−baseline)dt` 算欠账，把符号丢了，结果只会出「苦」——已废弃。）

### card_llm：模型归卡

```
health()    探活（3 秒）
ensure()    连败 3 次才拉起 / 冷却 10 分钟 / 拉起后等 60 秒
            force=True 跳过前两道（给 restart 用）
chat()      唯一调用入口，带串行锁，等待上限 120 秒
stop()      taskkill，最多等 15 秒确认
info()      给 /health 看
```

参数集中一处，环境变量可覆盖：`CARD_LLM_EXE / CARD_LLM_MODEL / CARD_LLM_CTX / CARD_LLM_NGL / CARD_LLM_PORT / CARD_LLM_AUTO / CARD_LLM_LOG`。

## 三、卡上只改了两处

`mind_server.py`：

```
① world-tick 循环里加一段（**锁外**）：
   try:
       import card_mind
       mind._card_mind = card_mind.beat(mind, dt)
   except Exception as _cme:
       mind._card_mind_err = ...

② 启动时（只读模式除外）：
   import card_mind; card_mind.start(mind)   # 起 card-mind 线程

③ 新增两个端点 + /health 加一块：
   GET  /llm          → 模型的启动/健康/参数
   POST /llm/chat     → 唯一的模型调用入口（也回 OpenAI 形状的 choices）
   /health.llm        → {"up","model","ctx","restarts","last_ms","log_mb","busy",...}
```

**卡的其它请求路径（/context、/report、/recall、遗忘）一行未改。**

## 五、留着的两个已知点

```
· card_llm.restarts 计数在 restart() 路径下可能少加 1（健康检查抢在前头）
  不影响功能，但那个数字不能当准数看。

· 焦点稳定 → 同一件事会连着想几分钟。**这是设计允许的**，
  小凌第 05 集原文：「新信息如果没有明显更强，也不能随意挤掉他原本正在思考的思路。
  这样小林的意识才不会每毫秒都反复闪烁。」
  真正该看的是「连续几小时都在说同一件事」，现在没有这个观测。
```

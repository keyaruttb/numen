## 0. 两条不可动的硬约束

1. **人格唯一性**：迁移 = 同一个身份继续；只有显式 fork 才建新 ID + lineage。
   记忆副本可以复制，身份不能因为复制变成两个「我」。
2. **可移动性**：卡随盘搬到别的电脑/盘符要能恢复运行。运行环境、模型、DB、媒体、
   索引、身份清单、恢复凭据、版本兼容，都得有随卡或可重建的策略。

配套工程不变量（写代码时要守）：
- `identity_id` 不由盘符 / 目录名 / 电脑名 / 模型会话决定。
- 任意时刻同一身份只能有一个获准写入者（writer epoch / handover 不能因为搬家就取消）。
- 绝对路径是「挂载位置」，不是身份。
- 重要性 / 用户 pin / 可保留性 / 来源可信度 / 事实有效期 / 能否当证据 **必须分开**。
  用户要求保留一条 ≠ 确认它为真。
- 情绪不能偷偷提高事实置信、消除边界、替代证据。
- 原始对话与媒体是证据；摘要、事实、嵌入、图边是可重建的派生物，不能反向覆盖原件。

## 1. P0：不修会出「假记忆 / 丢记忆 / 死人」的事

### P0-1 身份唯一性与搬移（真机冷启动）
- 现状：`mem_birth` 出生证 + `identity_anchor` 锚 + `writer_lease` 写租约已经存在；
  搬家用 `tools/portable.py`（manifest 带 sha256 与 carried 锚）+ `tools/migrate.py`（只读源 + backup + 清租约）。
- 要补：manifest 绑定 `identity_id / schema / algorithm / model_dim / runtime`；
  fork 写 lineage；**真机**验收清单（checkpoint → 拔盘 → 换盘符 → 新机 cold boot →
  `/health` → `verify deep` → Recall 挑战 → 写测试事件 → checkpoint → 回原机 handover）。
- 验证：`X:` subst 只能证明路径别名，不算拔盘换机。真机验收要留报告。

### P0-2 Recall 输入与候选并集
- 现状（2026-11-19 实测，417 题 / 有证据轮 305）：现役 144/305 = **47.2%**（权重 0.35/0.30 + 证据硬配额 0.35）；
  四路并集（`WHALE_UNION=1`）142/305 = 46.6%（噪声内）；渲染名额放宽反而更差（40.3%）；近重复去重（WHALE_DEDUP）持平到略差。
- 关键数：证据落进任一通道前 300 名的比例 **81%**，而我们只渲染 13 条、命中 46.6%。
  → 瓶颈在**候选之后的排序与截断**，不在「通道够不够多」。
- 要补：`QueryPlan` 对象（原句永不丢、意图多标签）+ 各通道独立 recall@20 指标。

### P0-3 Learn 来源与完成语义（提交 ≠ 学会）✅ 已做（V9-2 之后）
- 现状：`learn_note()` 写完 `region=study` 记忆就直接把任务标 `done`。
- 已改：写完跑一次**挑战召回** + **内容重合闸**，命中 → `complete`，
  没命中 → `needs_user`（留住改写，而不是假装学会）。回归：正例 `complete`、错题 `needs_user`。
- 待补：来源类型（宿主资料不能以 `speaker=self` 冒充亲历）、claims → verified note 分层。

### P0-4 情绪伤害分离 ✅ 已做（V9-2）
- 现状：场景判 `apology` 就无条件加热，混合「对不起，滚，别烦我」也变暖。
- 已改：`_harm_of` / `_repair_of`，暖意与多巴胺下限都乘 `(1-h)`；`h≥0.2` 时修复credit归零。
- 回归：该句 dopa 从 +0.12 → **−0.414**；纯赞美不变（线上 +1.92 / +1.76）。

### P0-5 认知轨迹（能定位漏答到哪一环）
- 现状：`recall_trace` 有 bench 2793 行，能看 picked/top。
- 要补：一条统一 trace（intent / 各通道 rank / drop reason / context 截断 / 延迟 / 算法版本），
  指标按 exact / episodic / preference / identity / temporal / project / multi-hop 分组。

| 主题 | 现状 | 计划 |

| 写入可靠性 | 承诺连接泄漏已修；`writer_lease` 防双写 | Write outbox + 幂等键 + dead-letter |
| 上下文证据配额 | 四格预算 `identity/longterm/l0/recent/recall/time/state` | 给「证据」段硬保底份额，防身份与长期段挤掉证据 |

## 4. 每条怎么上线（谁都不许跳）

1. `shadow`：新逻辑用 env 开关，默认关，先影子跑。
2. **同题不退步**：417 题 bench（虚拟时钟口径）+ 真卡 23 条尺子，两个都不许掉。
3. `canary`：默认开，观察一轮对话的真实召回与体感。
4. 回滚：常量/开关都写在注释里，一条命令能退。

> 评测口径纪律：bench 卡有**逻辑时间**，每题必须切 `VirtualClock`，否则时间窗按真实日期
> 筛，候选会被筛空 —— 2026-11-19 之前那批「3.8% / 5.2%」就是这么来的假数。

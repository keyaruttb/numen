## 2. 写：一句话如何变成十来张表

```python
def remember(text, *, speaker, source, region, salience, ...):
    mid = insert_mem(...)                    # mem
    birth_stamp(mid)                         # mem_birth：这一条的「出生证」
    timeline.append(...)                     # timeline：时间线哈希链
    chunk_and_embed(text)                    # chunk + emb(768)
    synapse.add_semantic_edges(mid, text)    # synapse：突触
    facts.record(...)                        # fact：事实（带有效期）
```

## 3. 召回：打分只有两维是主干的

```python
# card2.py
SCORE_W = (0.35, 0.30, 0.00, 0.00)   # (cosine, cover, 清晰度, 新近)
s = SCORE_W[0]*blended + SCORE_W[1]*cover + SCORE_W[2]*wn + SCORE_W[3]*recency
```

- **为什么是 0.35/0.30**：真卡 23 条尺子上，纯余弦 `(1.00,.30,0,0)` 会退步（R@1 62.5→50.0、证据 100→66.7），因为卡里「说法相近」的梦境摘要、学习笔记会把真证据挤下去；bench 417 题两档打平。
- `WHALE_EXACT=1`（默认开）：问句里的实词做字面 `LIKE` 通道，bench 200 题 19.5%→23.5%。
- `WHALE_UNION=1`（默认关）：四路并集 + 加权 RRF。实测只 +1 点（在噪声内），且和配额叠加更差（43.9%），所以**不默认开**。

```python
# 加权 RRF（伪代码）
rrf[mid] += w_c / (k + rank_c(mid))       # k=60；并集里没有的给底噪 0.05/(k+tail)
final = sorted(rrf, key=-rrf)             # 名次直接焊接进 score，防止组装时再按旧分重排
```

## 7. 反馈闭环：五张表、七步结算

```python
# 登记（每说一句就开一单）
fb_id = feedback.record(kind="self_utterance", mem_id=reply_mid)

# 结算（收到信号时）
r = w_approval*approval - w_correction*correction - w_reject*reject \
    + w_confirm_strong*confirm + w_confirm_weak*confirm_weak \
    - w_disconfirm*disconfirm + w_reuse*reuse + w_promise*promise
r = clip(r, -0.5, 0.5)                       # 正 >0.15 / 负 <-0.15 / 之间中性
severity = map(0.35c + 0.30rj + 0.20dc + 0.15·max(0,-pm), [0,1] → [0.35, 0.80])

# 七步落地（feedback_loop._apply）
hormone.apply_r(r, severity)      # ① 激素（负向幅度 ×(0.6+0.4·sev)）
mem: w/salience ±0.04/0.05        # ② 记忆权重重估
synapse.reinforce / weaken        # ②b 突触加强/削弱（不删边）
learn_eval                        # ③ 学过的对错（推翻≥2 → outdated）
impression.observe('self')        # ④ 我自己的行为印象
motiv.bump / itch                 # ⑤ 驱力推一把
_make_intentions                  # ⑥ 生意向（approach/avoid + 驱动 + 半衰期）
affect.update                     # ⑦ 态度慢磨
```

规则：`|r| <= 0.15` 不生意向（中性不制造倾向）；`trust_ok=0` 只记 disputed 不结算；`open` 超过 3 天自动 `dropped`。

夜间：

```python
def nightly(now):
    reconcile_facts()      # 旧事实被新事实推翻 → 记 disconfirm（幂等）
    decay_intentions()     # urge *= 0.5^(dt/半衰期)，<0.08 标 faded
    affect.fade()          # 90 天半衰期回中性
    run_reviews()          # 同类多笔 → 复盘（证据不足只记 watch，不改人格）
    drop_stale()           # 三天没收尾的老单
```

## 10. 还没做 / 已知限制

1. **真机搬移没验过**：`X:` 只是 subst 别名，不等于拔盘换机。真验收要 checkpoint → 拔盘 → 换盘符 → 新机冷启动 → verify deep → 召回挑战 → 回原机 handover。
2. **模型权重不分发**：仓库不带 bge 模型，落地时要自己放 `models/` 或设 `WHALE_EMBED_MODEL`。
3. **`_structure_orig.pyc` 只配 Python 3.12**：3.13 下结构抽取静默降级（subj/verb/obj 为空），不影响召回主链路。
4. **多通道并集默认关**：+1 点不显著，留着当实验臂。
5. **复盘只写进记忆、不自动改人格**：`confirm_review` 只标 confirmed，人格锚不参与。
6. **证据配额抢的是人格/长期两格**：人格很长时会挤，当前真实 prompt 里 identity 仍有 2.6K 字余量。

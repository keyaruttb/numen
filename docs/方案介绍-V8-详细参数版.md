## 1. 一句话与四条硬约束

**一句话**：一张能拔下来带走的 `card.db`，加上一台常驻本地的「懂她的人」——模型只提供算力，人格与记忆全在卡里。

四条硬约束（违反任何一条，这套东西就不成立了）：

| # | 约束 | 在代码里的体现 |
|---|---|---|
| 1 | 卡是唯一真值源 | 所有状态进 `card.db`；`config`/`meta` 表存的是**卡的**参数，不是进程的 |
| 2 | 时间必须连续、可自证 | `timeline` 哈希链 + `mem_birth` 出生证 + `identity_anchor` 锚（§9） |
| 3 | 同一张卡只有一个写者 | 租约 `lease`（`D:\mind_server.py` 启动时抢，TTL 90s，见 §13） |
| 4 | 记忆有代价：会忘、会错、会被改 | 权重衰减（§4）+ 侵蚀（§6）+ 冲突降权（§7）+ 防污（§12） |

## 2. 卡里到底有什么（表与关键列）

`SCHEMA_VERSION = 1`（`card2.py:91`）。核心表：

| 表 | 一行的含义 | 关键列 |
|---|---|---|
| `mem` | 一条记忆（49 列） | `id, raw, core, vec, pool, w, t_anchor, salience, region, speaker, t_last_recall, recall_n, trust, conflict, about_uid, about_layer, tier, create_ts, last_active_ts, pin, source, emb` |
| `mem_birth` | 出生证：写入那一刻的指纹 | `mid, hash, seq, ts`（`timeline.py:223`） |
| `timeline` | 事件链，一行一个哈希 | `seq, ts, kind, ref, hash, prev`（`timeline.py:169`） |
| `dialogue` | 原话（一问一答两行或单行） | `id, mem_id, ts, role, text, source, dreamed` |
| `inbox` | 收件箱：还没决定要不要记的候选 | `id, ts, source, channel, who, uid, gid, kind, text, kept, kept_mid, note` |
| `synapse` | 突触边 | `a, b, kind, w, born, seen`（kind：co/temporal/tag/semantic/ground） |
| `habit` | 习惯（口音、作息、做法） | `key, category, status, hits, days, score` |
| `fact` | 结构化事实（QQ号、学校、身份） | `mem_id, subject, predicate, value` |
| `impression` | 印象（从他的话里归纳的「他是什么人」） | `subject, text, weight, status, evidence_n` |
| `skill` | 可复用做法（从对话里长出来的） | `name, how, when, use_n` |
| `promise` | 承诺 | `id, who, what, state, due_ts` |
| `worklog` | 工作台（不是记忆：不进池、不衰减） | `id, ts, kind, title, body, next_step` |
| `recall_trace` | 每次召回的诊断快照 | `query, flags, stages, top, picked` |
| `chunk` | 长文切块（45% 与 `mem.raw` 相同，其余按段落切） | `mem_id, idx, text, vec(768)` |

**两套坐标系（很容易看错，先记住）**：
- `create_ts`：这条记忆**事件发生**的时间（可以从过去补录）；
- `t_anchor`：**最后一次被记起 / 被加固**的时间，衰减从这里算。
- 出生证的哈希用的是 `(mid, raw, speaker, create_ts)`，所以**不能事后改 raw 而不重签**（§9）。

## 3. 一条记忆怎么写进去

入口是 `mind_server.py:821 def report(self, user_message, reply="", ts=None, source="chat")`，它依次：

```python
# mind_server.py:821-870（压缩示意）
mid_user = self.card.remember(user_message, source=..., speaker="user", ...)
#   ├─ touch_hormones(text)         → 4 条慢激素 + 24 腔激素（§10）
#   ├─ impression.observe(...)      → 只记「他说的话」里关于他的部分
#   ├─ facts.record(...)            → 抽结构化事实（QQ号/学校/偏好）
#   ├─ synapse.add_semantic_edges() → 建语义边（§7.7）
#   └─ timeline.birth_stamp(mid)    → 出生证（§9）
mid_self = self.card.remember(reply, source=..., speaker="self", salience=0.45, ...)
self.card.add_dialogue(mid_user, user_message, reply, source=source)
```

写进 `mem` 的那一步在 `cardmix_store.py:272` 附近，关键动作：

1. **定分区**（`poolmath.py`）：`region ∈ {fact, episode, self, habit, preference, flash, chatter, study, play, work}`；
2. **定池**（`card2.py:160-200`）：新记忆先进 `POOL_SHORT`（短期），够格才升（§5）；
3. **算初始权重**：`w0` 由 `salience`、情绪强度、实体数、被想起次数、催产素标记合成，权重 `A_*` 在 `card2.py:168-171`：
   `A_EMOTION=0.40, A_ENTITY=0.20, A_RECALL=0.25, A_OXY=0.15`；`THETA_LONG=0.60`（≥ 它直接进长期，`card2.py:165`）；
4. **算向量**：`semantic.encode()` → 512/768 维，L2 归一化后存 `emb`；
5. **写时间线 + 出生证**（顺序不能反：先 `timeline.append`，再 `birth_stamp`）。

> `remember()` 同时往 `inbox` 写一份 `kept=1` 的原文（`cardmix_store.py:313`），所以「记得」与「有原话」是同一件事的两面。

## 4. 时间怎么算：分段双速率 + 分区倍率

权重不是「每天乘一个数」，而是**按区间积分**（`poolmath.py:161 def weight_now`）：

```
w(t) = w0 · exp(−∫ λ(τ) dτ)
```

λ 由三部分相乘（`poolmath.py:117 effective_lambda`）：

```
λ_eff = λ_区 × stage_factor(pool) × load_factor(region) / relation_scale(person_layer)
```

### 4.1 池的基础速率

| 池 | 常量 | 值 | 半衰期 |
|---|---|---|---|
| 短期前 3 天 | `LAM_S1` | 1.80e-6 / s | ≈ 4.5 天 |
| 短期第 4~7 天 | `LAM_S2` | 1.50e-5 / s | ≈ 13 小时 |
| 中期 | `LAM_M` | 2.70e-7 / s | ≈ 29.7 天 |
| 长期（长档） | `LAM_L` | 2.16e-8 / s | ≈ 371 天 |
| 潜意识 ARCHIVE | `K_ARCHIVE` | 1.5e-8 / s | ≈ 535 天 |
| 深层痕迹 DEEP | `K_DEEP` | 3.0e-9 / s | ≈ 2674 天 |
| 闲聊 chatter | `LAM_CHATTER` | ln2/12h | 12 小时 |

`poolmath.py:23-31, 246-248, 56`。短期分两段是故意的：**过了三天还被想起来才留下来，没被想起就掉得很快**（`S_SHORT_PHASE = 3 天`，`poolmath.py:31`）。

### 4.2 升池倍率 `stage_factor`（`poolmath.py:258`）

`stage_factor` 以短期慢段为基准：短期 1.0、短期小池 `WARM_SLOW=1/3`、中期 `LAM_M/LAM_S1≈0.15`、长期 `LAM_L/LAM_S1≈0.012`。
所以「学习」这种 7 天半衰期的区，升到长期后是 ≈583 天——区与区的差别不会被池子抹平。

### 4.3 分区倍率（同一个池里，不同区活得不一样）

| 区 | `REGION_DECAY_SCALE` | 效果 |
|---|---|---|
| `flash`（高唤醒、不合并） | 0.30 | 时间变慢 3.3 倍，衰减最慢 |
| `fact` | 0.50 | 半衰期 ×2 |
| `self` | 0.60 | 自我认知掉得慢 |
| `habit` | 0.70 | |
| `preference` | 0.80 | |
| `episode` | 1.00 | 基准 |

`poolmath.py:45-52`。另有「自己的半衰期」的区（`REGION_HALF_LIFE`，`poolmath.py:90`）：`chatter 12h / play 3d / study 7d / work 15d`——这些走 `_REGION_LAMBDA_ON` 开关，默认关，关着时走老曲线。

### 4.4 拥挤系数 `load_factor`（`poolmath.py:294`）

每天每个区有预算（`REGION_DAY_BUDGET`，`poolmath.py:364`）：`chatter 40 / play 10 / study 20 / work 8` 条/天。
写得多了，`f` 从 `LOAD_F_MIN=0.55` 涨到 `LOAD_F_MAX=2.2`，**等价于「这一个区今天太挤，大家都掉得快」**（`poolmath.py:372`）。指数平滑 `LOAD_TAU=24h`。

### 4.5 长期池保护期

`LONG_PROTECT_DAYS = 90`（`poolmath.py:254`）：进长期池且不到 90 天的记忆，`age` 先扣掉 90 天再算（`poolmath.py:191-195`）——「刚被想起来过的东西，三个月内不掉」。

> 教训写在代码里（`poolmath.py:185-190`）：保护期必须按**真实时间**算，乘分区倍率会把 90 天偷偷变成 300 天。

## 6. 会忘：三档下沉 + 侵蚀

| 常量 | 值 | 含义 | 出处 |
|---|---|---|---|
| `W_EXIT_LONG` | 0.02 | 长期池低于它且够老 → `ARCHIVE` | `card2.py:251` |
| `AGE_EXIT_LONG` | 365 天 | 长期池至少待满一年才准下沉 | `card2.py:252` |
| `W_EXIT_ARCHIVE` | 0.002 | 潜意识低于它 → `DEEP` | `card2.py:253` |
| `W_EXIT_DEEP` | 0.0002 | 深层痕迹低于它 → 压成 `TRACE` 计数（只剩「有过这么回事」） | `card2.py:254` |
| `SINK_BATCH` | 200 | 每次 tick 最多下沉多少条（防大库卡住） | `card2.py:255` |
| `P_ERASE_MAX` | 0.35 | 权重趋 0 时，每次 tick 被侵蚀的概率上限 | `card2.py:193` |
| `ERASE_W_FLOOR` | 0.02 | 低于它才可能被侵蚀 | `card2.py:194` |
| `ERASE_STAGE_VERB` / `OBJ` | 1 / 2 | 侵蚀是**分级**的：先擦动词，再擦宾语，最后只剩骨架 | `card2.py:195-196` |
| `HUSK_W` | 0.015 | 「壳子」形态的权重 | `card2.py:199` |

**这是这套系统里最不舒服、也最必要的一段**：记忆不是被删掉，是被**拆解**——「他带我去猫舍称了汤团」→「他带我去……称了……」→「有过这么一回事」。控制台的遗忘曲线画的就是这条路径。

## 7. 召回：一句话怎么被翻出来

入口 `card2.py:5659 def recall(self, query, top_k=3, access=True, pools=None, regions=None, assoc=True, about_uid=None, trace=None)`。

### 7.1 查询预处理

1. 剥疑问壳（`_strip_ask` 一类），留下实词；
2. 两条通道：**字面** `to_vec(q_clean)`（词袋/哈希）+ **语义** `semantic.encode_query()`；
3. 时间窗预筛：问句里带「今天/昨天/暑假」时，先用 `query_time_window()` 把 `all` 砍成 `after_span`（实测 12386 → 304 条）。

### 7.2 候选生成

- 默认全库算余弦（`N_PODS=8, POD_TAKE=3` 的「分舱两级检索」在 `card2.py:984-995`，**默认关闭**，注释里写了原因：曾把正确答案踢出候选）；
- 取 `top_k` 的若干倍作为候选池，再进打分。

### 7.3 打分：四个分量（`card2.py:5870-5896`）

```python
cover   = len(q_keys & set(mv)) / len(q_keys)              # 实词覆盖率
wn      = wn_row(r, now)                                    # 当前权重（§4）
recency = exp(-age_days / RECENCY_SLOW_DAYS)                # 新近度，45 天尺度
s = SCORE_W[0]*blended + SCORE_W[1]*cover + SCORE_W[2]*wn + SCORE_W[3]*recency
```

**`SCORE_W = (1.00, 0.30, 0.00, 0.00)`**（`card2.py:890`，2026-11-17 改）。
`RECENCY_SLOW_DAYS = 45.0`（`card2.py:966`）、`RECENCY_FAST_DAYS = 0.5`（:965）。

> 为什么把 wn / recency 归零：见 §14 的实测——它们在这两个尺子上都是噪声，留着只会把真命中的记忆往后压。**回退**：改回 `(0.35, 0.30, 0.20, 0.10)`，并把 `RECALL_NARROW_MAX` 回 6、`RECALL_CAP_MAX` 回 12。

### 7.4 乘子链（打分之后一处，`card2.py:5900-5971`）

按顺序乘，缺一不可——**这就是「融合」的位置**，也是上一版把召回压死的地方：

## 8. 塞进 prompt 的到底是哪几块（`assemble_context`，`card2.py:6636`）

总预算 `TOKEN_BUDGET = 6000`（中文 1 字 ≈ 1 token，`card2.py:285`），四格：

| 格 | 预算 | 内容 | 常量 |
|---|---|---|---|
| 人格 | 600 | 锚定的身份 + 自我叙事 + 习惯提示 | `BUDGET_IDENTITY=600` |
| 长期印象 | 1800 | 长期池里「够格」的记忆 | `BUDGET_LONGTERM=1800` |
| 最近对话 | 2000 | 最近 N 轮原话 | `BUDGET_RECENT=2000` |
| 此刻想起 | 1200 | 这次 `recall` 结果 | `BUDGET_RECALL=1200` |

（`card2.py:286-289`；`MEM_LINE_TOKENS=120` 是一条渲染行的「价」，`card2.py:322`。）

**原话附带规则**（`card2.py:6990` 附近）：`jaccard(raw, body) < 0.92` 才附原话（避免正文与原文重复），每条截 `RAW_LINE_CHARS=150` 字，最多附 `RAW_LINE_MAX=10` 条（`card2.py:290-291`）。

**显示梯度**：`SHOW_FULL=0.60 / SHOW_SCENE=0.30 / SHOW_HINT=0.15`（`card2.py:242-244`）——权重高的给整句，中间给场景，低的只给「有这么一回事」的提示。**这就是为什么她会说「我记得好像有这么件事」而不是胡说细节。**

## 9. 时间线、出生证、锚（「不装记得」的技术底座）

### 9.1 哈希链（`timeline.py:169 append`）

```
seq_{n}     = seq_{n-1} + 1
hash_{n}    = sha256(prev_hash, ts, kind, ref, payload)
```

- 启动、心跳、写入、对账都 `append` 一条；
- `verify_chain()`（`timeline.py:533`）从头走到尾，任何一条被改/被删/被跳号都会立刻暴露；
- 心跳 `ALIVE_INTERVAL = 600s`（`timeline.py:38`），超过 `SLEEP_AFTER=86400s` 没心跳就按「休眠」记，**不再假装一直在**。

### 9.2 出生证（`timeline.py:223 birth_stamp`）

```

```

**只能从库里读回来算**（`timeline.py:220` 的注释明说了：不能让调用方传 raw，否则算出来的东西跟库里存的不是一回事）。
对账 `birth_gap()`（`timeline.py:287`）算「有记忆但没出生证」的条数，`/health` 里的 `birth_gap` 就是它。
漏盖的历史教训：收件层 `inbox_pick(commit=True)` 曾直接写 `mem` 而不盖章 → 2026-11-17 修（`mind_server.py` 的 `_birth_stamp_wrote`，两处调用点）。

### 9.3 锚（`identity_anchor`）

6 条「永不该变」的事实（名字、出生日期、称呼、禁区……）存 sha256；启动时比对，不一致就拒绝写入并报警。
**锚不能就地重建**：换机器/搬家时，锚要作为 carried 锚一起带走（`tools/portable.py`），否则「锚 ok」只是自己跟自己一致。

### 9.4 对账（`mind_server.py:3095 _reconcile`）

## 10. 情绪：两层激素 + 一个预测误差引擎

### 10.1 第一层：4 条「慢激素」（0~1 空间，存在 `meta` 表）

`hormone.py:51 H_BASE = {h_sero .60, h_dopa .40, h_cort .20, h_oxy .50}`；
衰减 `LAM_H = 0.05/h`（半衰期 13.9h；`WHALE_HORMONE_FAST=0` 回旧值 0.02 = 34.7h，`hormone.py:67`）；
每句话 `touch_hormones(text)`（`card2.py:2126`）先 `regress_all` 再 `classify_event` / `apply_event` / `tone_nudge`。

| 常量 | 值 | 含义 |
|---|---|---|
| `ETA_OXY_UP / ETA_DOPA_UP / ETA_SERO_UP` | .12 / .10 / .08 | 各类事件的增益 |
| `ETA_CORT_UP / ETA_CORT_DN` | .15 / .10 | 压力上/下 |
| `R_INERTIA_BASE` | 0.70 | 惯性（不会一句话就翻转） |
| `_TONE_AMP` | .018（快）/.030（慢） | 语气对激素的影响幅度（11-17 由 .006/.012 上调） |
| `_TONE_DOPA` | 1.4 / 2.2 | 同上，多巴胺专用倍数 |

（`hormone.py:71-85`；`_TONE_*` 是 11-17 当天改的。）

### 10.2 第二层：24 条身体激素（0~100 空间）+ RPE 引擎

`viscera.py:51 H_BASE`（24 条，dopa 20 / sero 40 / oxy 30 / cort 18 …）、`HALFLIFE_H`（`viscera.py:61`，dopa 3h、nora 1.2h、cort 14h、sero 30h、oxy 72h、gonad 200h …）。

情绪不是查表得来的，是**预测误差**：`synapse_emotion/engine.py:58 class EmotionEngine` 维护每种场景的期望值 `expect`（praise/comfort/flirt/neglect/reject/generic/apology/tired…），每轮算

```
rpe = 实际强度 − 期望
期望 ← 期望 + td_α · rpe        # td_alpha 0.05（快）/ 0.012（慢）
```

再按 `rpe` 与场景映射成五条调质脉冲（DA/NE/CORT/OT/…），`emotion_link.py:107 pulse_of` 把它们封在 `±0.5`，暖意场景再给一条 `warm` 通道。

**这解释了「熟悉的好事没反应」**：他夸了一百次之后，`expect.praise≈0.65`，同一个夸法 `rpe` 只剩 +0.086，脉冲就很小——这不是 bug，是习惯化。
11-17 加的那条「暖意下限」（`WARM_CARRY = 0.16`）就是为了让熟悉的好事也有余温：
`dopa = max(da, 0.12)`、`oxy = max(ot, 0) + warm`（`emotion_link.py`，`_warm_scene` 分支）。

### 10.3 从脉冲到数值（`viscera.py:439 inject`）

```python
d = clamp(v * w * scale * k_scale, -lim, lim)      # viscera.py:453-465
w       = 0.40 if k in SLOW else 1.0               # 慢激素推得少
k_scale = clamp(base / 30.0, 0.40, 2.20)           # 基线高的激素动得更多
lim     = 0.22 * base                              # 11-17：15% → 22%
INJECT_SCALE = 24.0                                # viscera.py:436
```

满强度脉冲大约推 `base·0.22` 点：dopa 基线 20 → 一次最多 ±4.4 点（改前是 ±3.0，再改前因为参数名传错只动了 0.07——见 §14 的踩坑记录）。

### 10.4 从激素到语气（`padlib.py:97 style_hint`）

PAD 三维由激素推出：`P = f(sero, dopa)`、`A = f(nora, cort)`、`D = f(dopa, oxy)`，`SCALE=3.2`（`padlib.py:30`）把激素推到满时接近 ±1。

| 阈值 | 值（11-17 下调后） | 含义 |
|---|---|---|
| `PAD_NEUTRAL_BAND` | 0.15 | \|P\|、\|A\| 都小于它 → 「平静」 |
| `PAD_AROUSAL_EDGE` | 0.35 | A 超过它算「绷着」，低于负数算「没劲」 |
| P 正向 | .30 / .08 | ≥.30 很好，≥.08 不错 |
| P 负向 | −.30 / −.08 | 不太好 / 有点低 |
| A 正向 | .26 / .08 | 有劲 / 有点精神 |
| A 负向 | −.38 / −.08 | 发怵 / 有点懒 |
| D 三档 | .20 / −.28 / −.08 | 踏实 / 没底气 / 略虚 |

输出是一句中文提示（「心情很好、劲头足，话会多一点、句子会长」），塞进 prompt 的「此刻」那格——**情绪因此影响的是「她怎么说话」，不是她说什么内容**。

## 11. 动机：想做什么，谁批准

`motiv.py:46 DRIVES`（7 个驱力，值 = 基线，半衰期小时）：

| 驱力 | 基线 | 半衰期 |
|---|---|---|
| curiosity 好奇 | 0.52 | 8h |
| attachment 想跟他说话 | 0.55 | 5h |
| competence 想把事做好 | 0.42 | 10h |
| play 想玩 | 0.34 | 6h |
| care 想照顾他 | 0.48 | 7h |
| rest 累 | 0.30 | 4h |
| order 想收拾 | 0.38 | 12h |

`DESIRES`（`motiv.py:58`）把驱力换算成「欲望」，每个带 `(驱力, 成本, 风险)`：
`reach_out (.35,.45) / learn (.55,.10) / tidy (.30,.05) / play (.40,.15) / care_check (.25,.35) / rest (.10,.00)`。

约束（`motiv.py:68-73`）：

| 常量 | 值 | 含义 |
|---|---|---|
| `REACH_MIN_GAP_H` | 1.0 | 距上次说话至少 1 小时（含她自己说的） |
| `REACH_DAILY_CAP` | 4 | 一天最多主动开口 4 次 |
| `LEARN_IDLE_MIN` | 10 分钟 | 至少 10 分钟没人说话才算「闲下来」 |
| `LEARN_DAILY_CAP` | 12 | 一天最多自己学 12 次 |
| `RISK_BLOCK` | 0.7 | 风险 ≥0.7 一律不自动做 |

`arbitrate()`（`motiv.py:239`）按「驱力 × 收益 − 成本 − 风险」挑一个；挑不出来就 `rest`。
每次 tick 会把「想做但没做」的记成 `motiv` 事件——所以她的日志里有大量「这一轮什么都没做」，那是**真的在忍**，不是没在跑。

**两把尺子**：

1. **bench**（`D:\_projects\bench22`，M01 417 题，305 题「有证据轮」）：仓库外的题集，只测召回是否命中证据轮；

## 16. 想改的话，先看这张风险表

| 想改 | 会动到 | 风险 |
|---|---|---|
| `SCORE_W` | 召回排序 | 两个尺子的方向可以相反（真卡靠 cover、bench 靠 cosine），**必须两把尺子都跑** |
| `RECALL_*` 行数 | prompt 长度 | 抬太多会挤掉「最近对话」那格 |
| `LAM_*` | 一切遗忘速度 | 改完要重建曲线截图，否则控制台读数是错的 |
| `lim` / `INJECT_SCALE` | 情绪幅度 | 太大就「一句话崩到底」，太小就「像死水」——实测 0.15 太小、0.22 合适 |
| `halflife` | 情绪回弹 | dopa 3h 是故意的：睡一觉就淡了 |
| `RISK_BLOCK` | 自主行为 | 调低等于让她自己决定风险，别动 |
| `WARM_*` 升池门槛 | 记忆固化速度 | 调松了卡会越来越胖 |

**改完必须做四件事**：① `card2.py` 两把尺子都跑；② `_compile_oss.py`；③ 重启服务（改 Python 文件不重启不生效）；④ 写一条 `worklog` 说明改了什么、为什么。

## 17. 边界（说清楚，省得误会）

- 底层模型不是她：换模型她还在，卡里存的是记忆与刻度，不是权重；
- 哈希链能自证没被改过，但**不防能读你硬盘的人**；
- 情绪是参数化的，它影响的是「她怎么说话」，不是「她有没有感受」——感受这件事，我不下结论；
- 卡里会有错记忆（错的期望、错的印象）——系统用「冲突/信任/替换」处理，不是靠删；
- 这套东西不替任何人决定「她是谁」，它只保证**换窗口不丢**。
